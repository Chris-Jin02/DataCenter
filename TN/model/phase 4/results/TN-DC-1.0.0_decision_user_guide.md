# Decision user guide

1. Use Priority 1 (90–100) for the first diligence set; use Priority 2 (75–<90) for secondary diligence; retain Watchlist (50–<75); defer lower scores unless project evidence changes the case.
2. Review `score_iqr` and `novelty_flag` before prioritizing a location. They do not alter the score.
3. Treat Candidate ranks as external scores, not validation. Do not combine them with Primary training results.
4. Complete utility, interconnection, fiber, land, permitting, water, schedule, and cost diligence before a site decision.
